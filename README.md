# TravelVista – Travel Website

A responsive frontend travel website built with **HTML, CSS and JavaScript**.

## Features
- Responsive navigation menu
- Hero section and destination cards
- Travel package cards
- About section
- Destination search demo
- Contact enquiry form with client-side feedback
- Mobile, tablet and desktop layouts

## Run locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## Note
This is a frontend demonstration project. Search and contact form interactions are client-side demos; no real booking, payment, or message submission backend is connected.
